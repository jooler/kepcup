# 15 命令交互执行

Bot 的 shell 环境没有 TTY，stdin 默认关闭。交互式命令（sudo 密码、apt/yum 确认、安装菜单）会快速失败，不理会 EOF 的命令会一直挂到超时被杀，两种情况用户都无感知、无手段介入。本文定义命令行交互执行的设计：**非交互优先**为默认形态，确需人介入时提供**凭据注入**与**交互输入**两条受控通道。

## 原则

- **非交互优先**：能用非交互等价形式完成的命令（参数、环境变量、管道、expect）一律非交互执行，这是 Bot 自主工作的默认形态。
- 确实需要人介入时才走两条通道：**凭据注入**（sudo 密码、token 等敏感值）、**交互输入**（交互菜单、必须由人做的选择）。
- 红线：**凭据值与被标记为敏感的输入内容，不进模型上下文，不落对话消息、执行记录、审批行与审计**。

## 非交互优先

- bash 工具描述明确声明：无 TTY、stdin 默认关闭，不支持交互命令。
- 命令因等待输入而失败或超时时（输出尾部命中密码提示、`[y/n]`、选择菜单等特征），工具结果附引导：优先改用非交互等价形式（`--yes`、`DEBIAN_FRONTEND=noninteractive`、`sudo -S`、`ssh -o BatchMode=yes`、heredoc、`expect`）；确实无法避免时，以交互模式重新执行或申请凭据注入。
- 疑似交互提示的命令不必等满超时，提前终止并给出引导。

## 交互模式

Bot 发起，用户输入：

- bash 工具增加 `interactive` 参数。交互模式下命令的 stdin 以管道形式常开，输出实时推送到界面，用户在界面的输入直达进程 stdin。
- **只有用户能写 stdin**。模型不可直接向进程输入，但可以选择以交互模式发起命令（例如预期 `sudo -S` 需要密码、安装器要出菜单时）。
- 超时按**空闲超时**计：有输出或有用户输入即重置计时；取消执行即终止进程树。
- 交互会话是内存态，随执行存在：执行取消、应用重启即断开，不持久化、不恢复（与“重启即取消待确认”一致）。

## 输入可见性分层

- 输入框提供「敏感内容」开关；输出尾部命中密码类特征时默认开启，用户可修改。
- **普通输入**（菜单选择、确认项）：内容以回执行的形式进入本次工具结果——模型可见，并随工具结果记入执行记录，Bot 能据此继续决策。
- **敏感输入**（密码、token）：对模型只回执「用户输入了敏感内容（已隐藏）」，内容不出现在任何持久化位置。

## 凭据注入

- Bot 在 bash 工具调用中声明 `secret: { purpose }`（用途说明）：执行前发起 `secret` 审批（复用审批框架），卡片中用户以掩码方式输入，可选**记住到本对话结束**（存系统钥匙串，会话级）。
- 批准后，值在进程启动时写入其 stdin 第一行（适配 `sudo -S` 等从 stdin 读凭据的程序）；本对话内已记住的凭据自动使用，不再弹卡。对话删除时缓存一并清理。
- 审批行、审计、执行记录只含事件不含值；审批决定携带的值只在内存中流转。
- 程序不从 stdin 读凭据时不保证成功，工具结果引导 Bot 换用该程序的非交互方式（如 `sshpass`、key 文件）。

## 平台与降级

| 执行路径 | 交互模式 |
|---|---|
| srt 沙箱（macOS / Linux） | 支持 |
| 沙箱外 / 逐条确认模式 | 支持 |
| WSL2、容器增强后端（Lima、Podman） | 降级为非交互（stdin 被内部控制协议占用），工具结果如实注明 |
| Windows PowerShell 确认模式 | 降级为非交互 |
| 全屏 TUI 程序（vim、htop 等） | 不支持（无 PTY），引导改用非交互方式 |

降级是显式的：请求了交互但执行路径不支持时，按非交互执行并在工具结果中注明，绝不假装交互成功。

## 无人值守模式

在 [13-permissions.md](13-permissions.md#无人值守模式)「一律自动批准」之上：

- 交互模式命令照常执行；无人在场输入时按空闲超时结束，不产生挂起的确认。
- 凭据申请：已记住的凭据自动注入；没有可用凭据时**自动拒绝**并告知 Bot 改用非交互方式，绝不挂起等待。
- 开启弹框的自动批准清单与警告文案涵盖上述语义：无人值守期间凭据仅在已记住时可用，交互输入可能无人在场。

## 界面

- 执行步骤面板（Bot 状态行展开，见 [12-ui-layout.md](12-ui-layout.md#焦点二消息流末尾)）：交互模式命令显示实时输出尾部与单行输入框；疑似交互提示时显示徽标提醒。
- 凭据卡片：掩码输入、记住开关、醒目风险提示；决定后折叠为一行记录（不含值）。
- 左栏「待确认」标记与系统通知照常覆盖凭据申请（复用审批体系，不另做）。
