# KepCup 0.5.7

0.5.6 之后的版本。一个 Bot 委托另一个 Bot 时，双方改在专用的交换会话里沟通，你的对话里留下可点开的卡片。插件写明启用后还要做什么；缺了连接或绑定时，Bot 会主动提醒。模型设置里的供应商卡片更好认，长配置只在右侧滚动。侧栏的对话分组可以拖拽排序。计算机操控的滚动会核对页面是否真的动了。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **委托的交换会话**：Bot A 委托 Bot B 时，两人在单独的交换会话里直接沟通，这个会话不出现在左侧列表。你和 A、你和 B 的对话里各留一张卡片，点「查看详情」打开只读往来。委托还在进行时可以补充要求，也可以翻查过去的委托。任务过程留在交换会话里；需要你批准或回答的卡片出现在发出这次委托的对话中。提问类委托会等对方把派出的任务做完，再由发起方转述结论。交换会话里，发起方的消息靠右、对方的回复靠左，顶部有双方头像、名称和状态，左侧可以返回原对话。
- **插件启用说明**：每个插件带一段「启用说明」，写明启用之后还要做什么：直接可用、先连接账号，或先添加账号再勾选绑定。Bot 详情的插件卡和添加插件时都会展示这段说明。你添加或卸下插件、绑定邮件或微信账号、全局停用或删除账号之后，短时间内的连续操作会合成一条内部通报（不出现在对话里）。该做的步骤还没完成时，Bot 会发一条短消息，告诉你去哪里补上；全部就绪就保持沉默。扩展中心的市场和已安装列表增加「即时通讯」分类，微信插件可以在这里找到。官方市场的插件本版带上启用说明并升到 1.1.0，要求 KepCup 0.5.7 及以上，旧版本会在索引里滤掉这些包，避免下载后才因清单读不懂而失败。

## 改进

- **模型设置**：内置供应商卡片的副标题改为接口站点的域名，和填写了地址的供应商一致。每张卡片右侧有箭头，表示点进去是配置。宽屏下「模型」占满窗口剩余高度，只有右侧详情滚动，顶栏和左侧列表留在原处。从设置深链进来时，默认模型和向量来源会在详情里定位。
- **侧栏分组拖拽**：对话分组可以拖动排序。拖动时出现与侧栏同色的浮动副本，原来的位置留出占位，松手后平滑落到新位置。拖动距离不够时，点击仍然折叠或展开分组。右键菜单里的上移、下移保留。分组标题更紧凑，侧栏菜单左右留出间距。
- **计算机操控的滚动**：滚动之后会对比前后画面里元素的位置。看得到内容挪动时，动作说明写明大约移了多少，并提示按读回结果判断。读回确认没有变化时，说明这次可能是空转，并建议换一个元素、改坐标，或到前台再试。后台滚动会先把指针移到目标窗口里，再发出滚轮，让滚动落到那个窗口。
