# KepCup 0.5.0

0.4.0 之后的版本。扩展中心改为插件：技能、连接应用、工具和邮箱从插件市场安装，再添加到某个 Bot 或项目组，才会被它使用。官方市场这一批有 22 个插件，卡片带各自的图标。说明里补上了核心目标和核心思路。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- 插件市场：扩展中心是「市场」和「已安装」两个页签。市场可以搜索，并按技能、连接、工具、邮件筛选。认证插件在前，社区插件默认收起。安装前先看同意卡：技能、连接应用的服务地址和授权范围、工具的启动方式、邮件能力，以及插件声明要填写的配置。也可以从本地文件或文件夹安装，来源标为「未审核」：它的连接应用和工具每次调用都要你确认，没有持续授权。设置里的「插件」可以更换市场地址和签名公钥，用来接自建市场；自建来源最高按「社区」对待。有新版本时可以更新单条，或一次更新全部；权限变多时要重新同意。已被撤销的版本会提示，需要停用的会自动停用。对话里 Bot 可以建议安装市场中的插件，只有你在确认卡上点了才会安装。
- 安装之后还要添加：插件不会自动对每个 Bot 生效。装好后会提示到 Bot 详情或项目组设置的「插件」里添加，也可以「立即添加到 Bot」，并可以选择「以后不再提醒」。Bot 详情只列出已经添加的插件；没添加的，它的技能、工具和账号对这个 Bot 不可见。项目组里添加的插件只在这个项目的会话和任务中可用，不改成员 Bot 自己的配置。
- 官方插件与邮件：原先随应用附带的技能和连接应用改为从市场安装。这一批版本 1.0.1，各自有图标；没有图标时显示默认拼图图标。技能 9 个：Word 文档、Excel 表格、PPT 演示、PDF 处理、文档解析（MinerU）、会议纪要、周报日报、协作改稿、对内沟通稿。连接应用 9 个：Notion、Linear、Atlassian、Sentry、Canva、Stripe、Cloudflare、Google Calendar、Google Drive。邮件插件 4 个：QQ 邮箱、163 邮箱、126 邮箱、通用邮箱。邮箱在邮件插件卡上添加，一个插件可以有多个账号。QQ、163、126 锁定服务器，填写地址、用户名和授权码；通用邮箱要自己填 IMAP 和 SMTP。账号交给哪些 Bot 仍由你勾选。
- 插件上的设置：声明了配置的插件，卡片里有「设置」，表单按声明生成。敏感项显示已保存，留空表示保留原值。插件卡的「管理 · 工具」只列出这个插件提供的工具服务器。手动新建工具、安装 .mcpb、填写 OAuth 客户端，仍在没有限定到某个插件的视图里。

## 改进

- 扩展中心把原来的技能、连接、工具、邮件收进「已安装」的插件卡片。本机应用协作和本机自建连接改成带「系统」标记的卡片，展开后仍是原来的设置。市场列表改成按窗口宽度排列的卡片：宽的时候多列，变窄自动减列，同一行卡片等高，安装按钮对齐在底部。
- Bot 详情的「插件」放在「知识与能力」里，和技能、知识在一组。点加号从已安装的插件里搜索并添加，卡片上可以移除。还没有安装插件时，可以从这里打开插件商店。
- 私有化部署：网页里没有本机文件选择器。服务器上用 `kepcup-server plugin install <路径>` 安装本地 `.kepcup` 或插件目录，确认后再写入。
- 说明：README（中英）写上核心目标——思考与行动逻辑与真人一致的智能助理——和两条核心思路。对话是沟通记录，执行过程不必默认铺在对话里。双 Loop 先回复，需要执行时再单独跑任务，结束后由助理总结回复。要自己做插件，看 `docs/guides/write-a-plugin.md`：清单、配置与实例、打包和本地安装。

## 修复

- 扩展中心不再多出一条竖向滚动条，布局保持原来的宽度。
- 更新插件时，新版本里必填的敏感项留空会保留已保存的值。确认按钮不会因为这项空着而一直不可用。
- 插件更新删掉配置字段之后，设置仍能保存。已经不在清单里的旧项不会把整张表单卡住。
- 一次添加给多个 Bot 时，如果其中有已删除的 Bot，这次添加会整批取消，不会只写进排在前面的 Bot。
- 插件处于停用时去更新，更新完成后仍保持停用，不会把它的技能和工具重新打开。
- 卸载确认写明：会删除该插件创建的实例，例如邮箱账号和已保存的凭据，并断开它的连接应用账号。
