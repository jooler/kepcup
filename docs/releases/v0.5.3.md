# KepCup 0.5.3

0.5.2 之后的版本。macOS 上可以让任务操控本机（计算机操控），工作台备忘支持分组和拖拽，设置改为整页并把扩展中心收进来，最后一条用户消息改为撤回后改写重发，上传头像可以调内边距。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **计算机操控（macOS）**：任务里可以调用本机屏幕和键鼠。在设置的「计算机操控」里打开，并按引导授予辅助功能等系统权限。默认每次对话确认；无人值守不会自动批准。托盘可以随时停止。仅 macOS；网页端不提供。
- **备忘分组**：工作台备忘可以新建、重命名、折叠和删除分组，分组之间可以拖拽排序，备忘可以拖到别的组。事项可以在同一列里拖动排序；拖到别的列等于改派（进行中、待验收不能改派）。

## 改进

- **设置整页**：宽屏设置从弹框改为整页，左侧是分类，顶部可以返回对话。扩展中心并入设置页；原先设置里的「插件」收到扩展中心的「设置」页签。从通知、通讯录或搜索打开会话时会退出设置页。
- **撤回消息**：最后一条用户消息的「编辑」改为「撤回」。撤回后正文回到输入框，改写后可以重发；不再就地修改，也不再显示「已编辑」。转交的消息不能撤回。
- **头像边距**：上传头像可以设置 0–16 的内边距，让留白不同的图片看起来大小更接近。圆形和圆角方遮罩仍贴在图片本身上。
- **计算机操控设置**：从「浏览器资料」里拆成独立分区，并显示最近一次可用性检测。界面文案使用 KepCup，不再出现上游产品名。

## 修复

- 任务详情页会固定显示还没回答的提问卡（ask_user），不用退回对话才能作答。任务结束后提问不再出现。
- 计算机操控的 helper 入口路径已修正（开发与安装包里握手不再因为找错文件而失败、工具不注册）。握手失败会留下日志。与头像边距同时新增的数据库迁移已错开编号，应用可以正常启动。
