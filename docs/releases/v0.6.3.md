# KepCup 0.6.3

0.6.2 之后的版本。这一版为 Bot 消息增加了表情反馈与不当内容举报，并支持在本机界面隐藏某条消息（不影响模型上下文）。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **消息表情反馈与不当内容举报**：悬停 Bot 消息可添加表情。点 👎 会同时提交不当内容举报（无弹窗）；也可以通过右键菜单「举报不当内容」发起。发送前再次点击 👎 可撤回待发送的举报；已经发出的举报无法由用户撤回，可按隐私政策申请删除。隐私政策与使用条款已同步更新。
- **仅界面隐藏消息**：Bot 消息右键可「隐藏此消息」。隐藏后显示占位提示，本机侧栏预览、搜索摘要、引用和语音播报都不会再展示该内容。隐藏状态只保存在本机（按设备、查看者和团队账号），不会写入 Core 或团队库，模型上下文仍读取原文。可随时「显示此消息」恢复。
