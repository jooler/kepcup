# KepCup 0.5.15

0.5.14 之后的版本。这一版把百炼文生图试点插件转正为正式的「Qwen-Image 3.0 文生图」，并修正模型列表里上下文窗口的回填口径。已安装的桌面版会通过应用内更新收到这一版。

## 改进

- **百炼文生图试点转正**：插件名改为「Qwen-Image 3.0 文生图」，描述去掉「试点」措辞（1.2.1）。实现与 1.2.0 一致，只做元数据改名。

## 修复

- 拉取模型列表时，若响应缺少上下文窗口字段，会按 pi-ai 内置目录精确回填，不再把已收录的已知模型登记成 128k 猜测值。
- 同一模型 id 在目录里出现多供应商冲突时取最小窗口，避免高估后请求超出上游真实上限。
