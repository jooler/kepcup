# KepCup 0.5.9

0.5.8 之后的版本。微应用平台第一版落地：从契约、语音与模型网关，到包数据生命周期和制作流程，组件可以按清单声明能力，并在对话里或独立窗口中运行。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **微应用平台（P0–P3）**：清单与能力面、指纹与桥接、发布与门控；`ai.chat` / `session` 隔离网关与预算；`media.listen` / `media.speak` 宿主代理；多文件包、collections、context 注入、诊断与心跳；多文件 craft、能力 mock、SDK 文档与包模板。
- **组件独立窗口**：覆盖层里的微应用可以移交到独立 Electron 窗口继续跑。

## 改进

- **Web 会话过期**：过期后自动回到登录页，局域网 http 直连可正常启动。
- **组件容器**：高度撑满可用区域。

## 修复

- 微应用审查与验收中的门控、归属绑定、配额、分页、mock 闸门等一批问题。
- 「在新窗口打开」：Svelte `$state` 深代理无法结构化克隆导致的失败提示。
- 组件窗口加载完成后补发端口 A，避免一直停在「正在加载组件…」。
