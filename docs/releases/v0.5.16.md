# KepCup 0.5.16

0.5.15 之后的版本。这一版把模型调用统一为「对话 / 任务 / 后台」三类，并把任务执行引擎做成全局默认，设置页和 Bot 详情也按这个口径重新排了。已安装的桌面版会通过应用内更新收到这一版。

## 改进

- **模型调用三分类**：对话轮和后台整理（摘要、反思、记忆、画像、Wiki、技能生成）固定走内置引擎；外部智能体只用于任务。分诊、上下文压缩和微应用仍走轻量模型链。
- **任务执行引擎全局默认**：模型配置页新增「默认任务执行引擎」。Bot 上可跟随应用默认、显式使用内置引擎，或指定外部智能体；若所选智能体不可用，会回落到内置引擎。
- **后台任务模型**：新增全局「后台任务模型」，Bot 也可单独指定。未设置时各自回落到既有的轻量/主模型兜底。
- **设置与引导调整**：智能体页不再放全局配置入口；Bot 详情拆为主模型、轻量模型、任务执行引擎和后台任务。引导流程里默认主模型改为必选，并去掉外部智能体配置分支。
- 不再保留旧的「默认主智能体 / 后台智能体 / 后台任务」整块设置，以及「无默认主模型时新建 Bot 套用外部智能体」的降级路径。升级后请在模型配置页重新确认默认任务执行引擎和后台任务模型。
