# KepCup 0.6.1

0.6.0 之后的版本。这一版把 Computer Use 的 CuaDriver 从仅 macOS 扩展到 Windows 和 Linux，并随安装包一起分发；同时改进了 MCPB 扩展在本机找不到运行时时的检测与提示，并把 Electron 与 Pi 升到了新的补丁线。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **Computer Use 三端支持**：CuaDriver 现在在 macOS、Windows 和 Linux 上都可以用，并随发行版一起分发。权限面板按平台显示：Windows 上不再出现没有系统授权概念的「辅助功能 / 屏幕录制」两项；「打开系统设置」仅 macOS 提供。检测截屏探针在三端都保留。

## 改进

- **Electron 45.5.0 与 Pi 1.6.1**：桌面端升到 Electron 45.5.0（Chromium / Node 补丁更新）。智能体运行时 `@earendil-works/pi-*` 统一到 1.6.1，并把 undici 收敛到 8.12.4 以纳入安全修复。
- **MCPB 运行时检测**：受管运行时找不到时，会回退扫描系统 PATH（Windows 跳过 WindowsApps 别名并补 Program Files 默认目录；macOS 补上常见的 Homebrew 目录）。设置页和同意卡在缺失运行时时会给出更清楚的说明，桌面端还提供「下载 {runtime}」按钮。

## 修复

- MCPB 运行时缺失时的报错文案更清楚，并与中英双语界面同步。系统 PATH 里已经装好的运行时不再被误报为缺失。
