# KepCup 0.5.5

0.5.4 之后的版本。桌面壳升级到 Electron 45.2.1（Chromium 156、Node 24.22.1），跟进上游的安全与兼容性修复，屏幕捕获权限按新版 Electron 的上报方式同步收紧。已安装的桌面版会通过应用内更新收到这一版。

## 改进

- **桌面壳升级**：Electron 44.4.5 → 45.2.1，内置 Chromium 152 → 156、Node 24.21.0 → 24.22.1。网页内容、内置查看器与 PDF 预览随上游更新；原生模块仍是 Node-API 预编译产物，不需要重新编译。Linux 包的运行时依赖不变（RPM 依赖与 core24 基线实测仍满足）。
- **屏幕捕获权限**：Electron 45 起屏幕 / 窗口捕获统一以 `display-capture` 权限上报。KepCup 仍只放行应用界面的麦克风、摄像头、复制与全屏，屏幕共享继续被拒绝。
