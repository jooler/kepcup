# KepCup 0.5.11

0.5.10 之后的版本。这一版让声明了互不重叠写域的任务可以并行，并补上任务间协调；插件侧落地了 MCP 实例化，以及腾讯文档、飞书两个平台插件。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **并行写任务与任务间协调（D123）**：写互斥从「整个工作目录」细化到任务声明的写域；互不重叠的写任务可以并行，相交仍串行。任务可认领域内路径，并可向同对话的兄弟任务发消息、等待其结束。不声明写域的写任务行为与以前一致（整目录串行）。
- **MCP 实例化与平台插件（P4-M2）**：插件提供的 MCP 可以按实例配置（鉴权、请求头、敏感字段）。内置腾讯文档、飞书插件。
- **任务失败自动重试**：`start_task` 失败后按 1/2/3/5/8/13/21/34 分钟退避，最多再试 8 次，用尽才提示；等待期间不弹横幅。设置未完成、被中断或已取消的任务不会自动重试。
- **手机原生壳（D122）**：新增 `apps/mobile`（原生首页 + WebView 加载所连服务端托管的 web 客户端）。桌面与 headless 的 web 端已支持原生壳模式；配对凭证在壳内跨冷启动保留。手机应用本身按 APK / TestFlight 分发，不随这次桌面安装包发布。

## 改进

- 任务详情的直注输入坞改用对话里的 Composer（保留语音键；暂不支持附件；无语音对话模式）。
- 用户消息气泡改为 Markdown 渲染，与 Bot 气泡共用同一套组件；`@` 提及仍显示为胶囊。
- 智能体引擎升级到 Pi 1.5.2。

## 修复

- 写域相关文案与拦截更准确：简报按真实写域渲染，空写域不再出现 `writes=""`；域外写入和认领冲突不再误荐 `request_access`；绝对路径写域的拒绝说明单独列出。
- 任务上下文会写明自身一行，并带上启动前实际排队时长与原因。
