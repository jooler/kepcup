# KepCup 0.6.0

0.5.16 之后的版本。这一版把可自托管的团队服务器接到桌面端，并加固了任务沙箱与并行写；另外还有一批桌面体验改进。团队服务器本身是闭源商业组件，客户端接入与共享契约仍开源。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **团队服务器**：桌面端可连接自托管团队服务器（左下角头像菜单，或设置里独立的「团队服务器」分组）。连接是分步的，先做健康检查；也可以给本机上的服务器条目起名字，左栏等位置优先显示名称。Web 团队端点提供重排后的登录卡、条款与隐私页，成员可以自助更新资料。
- **团队协作**：成员面支持从「+」直接创建或从模板导入、为工作路径使用不透明标识，并在断线后自愈。好友层可发送申请、处理通知和拉黑。一对一私信的列表与头像规格已对齐，输入框不再显示多人会话才有意义的「N 人在此对话」。桌面端融合了团队协作视图，并加入客户端本地缓存。
- **团队 Bot 与分身**：在「+」菜单里按团队分组创建 Bot，支持团队建 Bot 访谈，以及管理「我的私有 Bot」。服务端提供分身运行时、决议卡和用量分摊；未读数口径在客户端与服务端之间已统一。
- **任务沙箱读宽写窄**：沙箱内默认可以读取整机（与文件工具的只读放行对齐），写入范围不变；原先会被自动放开的默认便利写路径已显式锁死。一次可以批准多条路径，任务审批增加「仅这一次 / 本任务内 / 本对话内」时长。
- **污点即断网**：对话处于污点期时，沙箱命令不再逐条向外网放行，而是直接切断外网（localhost 和绑定工作目录的端口保留）。模型可以通过一张 `request_network` 卡按所选时长重新联网，授权默认 60 分钟后失效。
- **写任务默认并行**：同一工作目录里的内置写任务改为共享写租约、默认并行，互斥下沉到文件级自动认领，并为每次运行保留影子快照。
- **可选 worktree 隔离**：任务可以在独立 git worktree 中运行（双根沙箱）。有改动时会出「应用到工作目录」卡，批准后再合并回来；也会回收长期无主的孤儿 worktree。外部智能体与部分沙箱后端不支持该模式。

## 改进

- **通用设置与对话展示**：通用设置条目做了收敛，并新增对话信息展示设置，可以控制对话列表里显示哪些内容。
- **更新下载**：更新按钮会显示下载进度，并配有进度卡片；取消即跳过该版本。
- **窗口布局**：宽屏下的中窄窗口，右栏改为覆盖抽屉，避免挤压主栏；红绿灯位置适配最窄左栏宽度。
- **任务命令可停**：任务详情里，正在运行的 shell 命令卡右上角会显示停止，经 `runs.cancel` 终止该命令进程树。
- Bot 详情简介支持多行展示与编辑；连续用户消息不再插入额外间隔。
- 扩展中心页签补上「设置」，深链指向与设计文档对齐。

## 修复

- 分身开关在首帧渲染时不再触发 `state_unsafe_mutation`。
- 窗口重载后补发端口时，不再把已不可达的团队服务器标签卡死在「已连接」。
- 启动时收敛旧的失败横幅；遇到比当前程序更高版本的数据库会明确拒绝启动，避免误用。
- Web 端在 RPC 绑定完成前先缓冲入站帧，不再卡在「核心服务启动中…」。
- 团队设置里免打扰草稿改为 effect 懒初始化，避免 Svelte 5 模板里写 `$state`。
- 团队服务器菜单入口与连接卡口径一致：Web 团队端点不再渲染桌面端的该入口。
