# KepCup 0.2.1

0.2.0 之后的小版本：远程遥控、Bot 自我进化闸门、HTML/组件预览与一批桌面体验修复。

## 新增

- 远程遥控（D96）：扫码/配对、按需中转、标签页独立凭证、头像菜单入口；连接存续期间阻止系统空闲休眠。
- Bot 自我进化 T1–T5（D97–D101）：反思技能建议证据闸、人设卡无人值守收紧、反思来源技能默认不自动启用、lesson 注入带日期证据。
- HTML 查看与 Bot 组件「完整 WebApp」档：海报 + 覆盖层运行；FileViewer HTML 预览外链转交系统浏览器。
- 任务 Loop 参数说明与设置项即改即存。

## 改进

- 侧栏图标模式拖拽带、FieldEditorCard 响应式、项目/桌面细节收尾。
- 本机调研报告：Agent 自我进化落地方案与 KepCup 对照（`docs/reports`）。

## 修复

- 远程：首扫无反馈、配对 accept→done 竞态、核心状态快照、暗色主题二维码可读性、僵尸 anchor 重连与迟到 reject 等审查项。
- 合并 main 上 0.2.0 发版后的 CI 加固（Windows 路径断言、share sweep、sandbox/status-line e2e）。

## 平台与安装包

与 0.2.0 相同：macOS dmg/zip、Windows 合并 NSIS、Linux AppImage/deb。已安装用户会经应用内更新收到本版。
