# KepCup 0.1.1

0.1.0 之后的小版本：侧栏与工作台体验、审批与权限、官网与多源更新。

## 新增

- 输入框 `@` 菜单可选择本地文件或文件夹。
- Bot 头像支持上传 SVG。
- 侧栏：Bot 按最近消息自动排序，并支持置顶；最后一条消息预览支持卡片摘要；删除对话改为列表，并提示 Bot 仍保留在通讯录。
- 工作台：备忘与事项左右互换，备忘卡片自适应居中。
- 画像：提示词引导可按分类查询完整画像条目。
- 权限：`git_remote`（push / pull / fetch）支持「本对话内一直允许」与「对该 Bot 总是允许」；中途权限卡通知改为内存态（不写消息表、不进 Bot 上下文）。
- 更新：多源选源（GitHub / R2 / OSS）与发布后镜像同步。
- 官网 [kepcup.app](https://kepcup.app) 上线（中英）。

## 改进

- 用户消息上下外边距，对话更易扫读。
- 侧栏图标模式：用分隔线区分 Bot 分组；macOS 保留顶部红绿灯拖拽区。
- 工作台：事项与备忘内容区统一限宽并对齐；刷新后直接恢复上次主视图。
- 移除全部 token 用量上限。
- README 中英完善；站点布局与双语文案重构。

## 修复

- 审批：命令成功时不因附带探测拦截误弹卡；任务越界访问自动弹卡并增加审批超时；无人值守横幅改为顶部浮动，避免撑出滚动条。
- 工作台：道头长名裁剪，稳住 sticky 选区工具栏；备忘卡片组整体居中。
- 桌面：dev 壳替换品牌图标，系统通知不再显示 Electron 图标。

## 平台与安装包

与 0.1.0 相同：macOS dmg/zip、Windows 合并 NSIS、Linux AppImage/deb。已安装用户会经应用内更新收到本版。
