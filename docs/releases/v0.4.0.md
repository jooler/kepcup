# KepCup 0.4.0

0.3.2 之后的版本。项目组多了看板：用分栏整理卡片，把卡片交给一位 Bot，并按时间或周期执行。Bot 在这张卡片自己的对话里讨论、执行和交付。Wiki 与界面做了整理。说明里写清两种用法：本地运行，以及在自己机器上的私有化部署。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- 项目看板：沟通、Wiki 之外的第三个模块。第一次打开会种下「待办 / 进行中 / 已完成」三栏（按当前语言），之后可以改标题、增删分栏、拖动排序。每栏顶部可以连续新建卡片；卡片可以在栏之间拖动，右键也可以上移、下移、移到其它分栏或删除。分栏只表示你怎么整理，不代表执行状态。还没指派的卡片是纯思路卡，卡面上不显示状态。
- 指派、排期与派发：把卡片交给项目里的一位 Bot。可以先定时间再指派——还没指派时，卡面和详情显示「待指派 · 时间」，也可以直接清掉。时间可以是现在、某个时刻，或重复（每天、工作日、每周几、每月几号）；重复至少间隔一小时。指派后不会马上开工：没有时间时是「待开始」，可以先在卡片对话里讨论，再点「开始执行」或设时间。到点（或点开始）会把卡片内容派发到这条对话。状态显示在卡面上，例如已排期、执行中、排队中、待验收、已完成；需要你处理时会有未读、待审批、等你回答一类提示。看板页签会汇总未读、待审批和待验收。
- 卡片对话：每张已指派的卡片有一条专属对话，不出现在侧栏、搜索或通讯录里。点开卡片是详情弹框：左边改正文（自动保存）并看执行记录，右边和执行成员聊天、处理审批、查看任务过程。可以上一条 / 下一条翻卡片。窄屏改成「详情 / 对话」两个页签。换人或取消指派后，原来的对话只读保留；成员离开项目或 Bot 被删除时，弹框会打开最近一条只读对话。删掉卡片会一并删掉它的对话。

## 改进

- 卡片长这样：正文最多显示六行。底部左侧是状态和时间，右下角是执行者头像。详情里状态、执行者和执行时间是字段行，主操作（开始执行、验收完成等）跟在状态下面。分栏头部的空白处可以整段拖动，标题和按钮仍可点、可改；分栏随内容增高，超出后卡片列表自己滚动。拖动时不再带出半透明的系统拖影。弹框外的上一条 / 下一条按钮改为不透明底。
- Wiki：提示文字和「历史」只在根目录出现，往下只用面包屑移动。页面不再单独放一行标题，面包屑末尾就是页名。删除页面收到面包屑行右侧的图标按钮，确认在原地展开，离开该页会取消。项目 Wiki 对齐设置页的居中版式，设置页也不再放「项目详情」标题行。
- 项目成员：成员弹层里不再内嵌添加成员。加人从「管理成员…」进入详情页的成员分区。
- 界面动效：弹框蒙层淡入淡出，内容淡入并略微上滑。右栏改为可拖拽收起的抽屉，收起动画结束后才卸掉内容。窄屏的 Bot 详情、设置页和搜索从侧边滑入；媒体灯箱淡入淡出。系统开启「减少动态效果」时，这些过渡会关掉。
- 左栏底部：用户头像略小一圈，扩展中心按钮的悬停和底色做了调整。
- 说明：README（中英）把用法写成同一产品的两种运行方式。本地运行是桌面应用，Bot、记忆、邮件和定时任务都在这台电脑上。私有化部署是在 NAS 或云服务器上跑 headless 服务端，手机或浏览器登录同一实例，笔记本合盖也能继续跑定时、邮件和回复。数据仍在你掌控的机器上。

## 修复

- 新建卡片时按 Esc 取消，接着发生的失焦不会把这张卡片存下来。
- 卡片刚建好、临时编号换成正式编号时，已经打开的弹框保持打开，排在这个编号上的正文和分栏标题会在替换后补存。
- 拖拽之后卡片仍是按钮：Enter 可以打开弹框。输入框因失焦而提交时，不会把焦点从你刚点到的控件上抢回来。
- 执行成员离开后，弹框会重新打开最近一条只读对话，而不是停在未指派的空状态。再次指派时，当前这条只读对话仍留着，不会被更早的一条盖住。
- 卡片对话开在旁边时，主会话保持原样：不会被换成这张卡片的会话，任务过程页也不会被它带走。
- 卡片对话不计入删除 Bot 时的预览。一次看板修改只通知一次；写到一半或拖动过程中到来的更新，会等这一步结束再应用。
