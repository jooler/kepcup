# KepCup 0.3.1

0.3.0 之后的版本。这一版带来个人资料：可以设置头像和名字，侧栏、对话和窄屏「我」页都会用上。对话里选中文字可以直接复制，引用一条消息时能看到图片缩略图。Bot 详情不再分页签，改成一张分组菜单，点进去再返回。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- 个人资料：设置的第一项。身份卡可以上传头像（先裁成正方形：拖动取景，滚轮、滑块或按钮缩放，旁边有圆形预览，保存为不超过 256×256 的 PNG），名字在卡片上直接改，停笔或点到别处即保存。下面是用户画像：一张卡片预览，以及基本信息、沟通偏好、工作与项目、兴趣与习惯、边界与禁忌、近期状态六类，点一行进入详情。头像和名字会出现在左栏、对话、项目头像叠层和窄屏「我」页。给 Bot 上传头像时用同一套裁剪。
- 选中即复制：在 Bot 对话里选中文字，工具条在「置顶」旁边多了复制。成功或失败都有提示；选区留着，还可以接着置顶。
- 引用回复带上附件：引用一条带附件的消息时，输入框上方的预览和消息里的引用块会显示图片缩略图（点击放大）、视频（在灯箱里播放），其它文件仍显示为文件。Bot 收到的上下文也会标出被引用的文字和附件，顺着你引用的那一条回答。旧的引用记录没有附件信息时，仍按原来的纯文字引用显示。

## 改进

- Bot 详情改成二级菜单：右栏去掉页签，换成一张分组菜单。组件放在最上面，可以直接打开；其余按工作目录、人设与引擎、知识、连接、任务、安全与授权、其它分组。点一行进入详情，返回回到菜单。原来的「组件」页签收进这条菜单，详情里可以发卡和删除。配置按条目分开填写。「应用」只列出正在用的，从已连接的账号里添加，也可以在行内移除。导出为模板挪到顶栏，和关闭按钮一样是圆形描边按钮。设置里的「应用」分区去掉，连接统一到扩展中心；从设置卡跳进来会落到对应的那一行。
- 左栏与边框：左栏右侧多一条分隔，和主区域隔开。全局边框加了透明度，线条更淡。暗色主题的背景略提亮，macOS 上左栏的毛玻璃也跟着调整。
- 左栏当前会话的高亮更克制：亮色下略压深一点，方便从底色里认出来；暗色下不再整块发亮。

## 修复

- 技能草稿：草稿上点「查看 SKILL.md」会去读草稿目录，不再误报「技能目录不存在」。草稿目录已经不在时，这条会从列表里清掉，并提示「草稿目录已不存在（可能已被删除或回收），条目已清理」。技能卡上的长说明、缺失依赖和报错路径会换行，不再横着撑出卡片。
