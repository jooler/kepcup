# KepCup 0.5.8

0.5.7 之后的版本。每段对话可以单独选权限级别：手动确认、自动授权或完全控制。顶栏盾牌用来切换，升到更高档要先勾选风险。任务详情按编程 Agent 的方式展示思考和成组的工具调用。Bot 之间的委托卡片改回左对齐，名称带上各自的强调色。侧栏和右栏的分隔条悬停时会出现拖拽提示。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **对话级权限三档**：聊天区和项目组顶栏各有一枚盾牌，按当前对话切换三档。绿盾是手动确认（默认）：越界写入、沙箱外执行等仍按授权卡片处理。深橙盾是自动授权：自动批准文件访问（含工作区以外的写入）、环境安装和技能导入；命令仍在沙箱里按规则执行，沙箱外执行、git 远程、MCP 写入和外部智能体仍会请求授权。红盾（盾牌关闭）是完全控制：跳过权限确认；网络策略为开放、或沙箱不可用，且这次不是只读执行时，可以脱离沙箱。升到自动授权或完全控制前要勾选风险说明，也可以选择若干小时后自动回到手动确认（1–168 小时；清空小时数不会切档）。设置只记在内存里，重启应用回到手动确认。委托的交换会话沿用发起那次对话的级别，看板卡片对话沿用项目组对话的级别。无人值守开启时，所有对话都按完全控制执行，盾牌显示这一档，下拉不可改。灾难性命令（如删掉根目录或系统目录、写裸设备、格式化磁盘、关机）和应用数据目录在完全控制下仍会被拒绝。判断不了的请求（未识别的类别、没有路径的写入、目标不确定）在无人值守和完全控制下也会直接拒绝。

## 改进

- **普通读取**：工作区以外的普通文件可以直接读，不再逐次要授权。敏感位置、应用数据目录，以及工作目录的保护规则仍然要授权。
- **任务详情**：打开任务后，思考内容折叠成一行「思考」，点开才看到原文。连续的工具调用收进一张卡，标题写出调用次数和失败次数；每一行是动词、目标和增删行数（新增为绿色、删除为红色）。点开某一行看原始命令和完整结果，悬停可以复制命令。工具还在跑时，进度只更新状态行，不再把「正在执行…」写进过程列表。
- **任务卡即时出现**：派出任务后，回复不再复述「已派出、开始做了」。卡片会马上出现在对话里；只有排队、能力不可用等情况才用一句话说明。转交或取消任务仍会说明去向。
- **委托消息**：对话里的委托卡片改为左对齐。交换会话顶部的标题里，双方名称使用各自 Bot 的强调色，头像也略大一些，连在一起的消息留出同样宽度的占位。
- **侧栏与分隔**：设置分类条目的悬停和选中底色与对话行同一套。拖动侧栏宽度，或拖动对话与右栏之间的分隔时，悬停会出现居中的拖拽条和提示；侧栏分隔还可以双击恢复默认宽度。macOS 窗口左上角的红绿灯整体右移、下移各 4 像素。浅色背景略深、深色背景略暗，侧栏条目更紧，消息气泡更圆、内边距更大。
- **语音消息**：气泡左侧的图标改为播放和暂停。正在播放时显示暂停，不再固定为麦克风。
- **说明文档**：README 写明共享消息板、项目 wiki 和看板第一版已经就绪。开发路线图把看板第一版、Bot 间委托和插件系统标为完成。

## 修复

- 去掉两处不影响行为的检查告警：授权卡片读取时长时不再触发界面检查警告；侧栏分组列表里未使用的索引导致的检查错误也已去掉。
