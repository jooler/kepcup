# KepCup 0.3.0

0.2.1 之后的版本。KepCup 是开源、本地优先的 Personal Agent（多 Bot 团队形态）：在你掌控的机器上创建多个 Bot，赋予权限与工作目录，它们与你协作，也彼此协作。这一版带来自托管 Headless 服务端，以及 Bot 模板的导出与导入。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- Headless 服务端（D102）：同一套对话、调度与记忆可以在 NAS 或云服务器上常驻自托管。浏览器打开地址，用账号和密码登录即可使用；首启会引导配置模型并创建管家 Bot。不需要 Docker，只要 Node.js。GitHub Release 附带 `kepcup-server` 的 tar.gz，可用 `npm i -g` 安装，也可解压后直接运行。设备配对仍可作为选项（`--auth pairing`）；走中转时仍使用配对。服务端暂无自动更新，重新安装即可，数据目录保留。
- Bot 模板导出/导入（D48）：右栏配置可将人设、能力与自写技能导出为 `*.kepcup-bot.json`；侧栏「新增」可从模板导入，导入前先看包含与剥离清单。导出会清掉私有数据，以及本机 MCP、连接等引用。
- 更新确认：新版本下载完成后，左栏更新会先弹出确认，再重启安装。

## 改进

- README（中英）：写明开源、本地优先 Personal Agent（多 Bot 团队形态）的定位，并补充 Headless 服务端的运行、登录与打包安装说明。
- Web 客户端：浏览器里左栏左上角始终显示 logo，按无系统窗口按钮的布局排版。长时间打开的页面在心跳中断后会自行重连。跳过首启向导时也会创建管家 Bot。

## 修复

- macOS 系统分享导入：空内容的分享面板会在约 4 秒后自动关闭；目标列表写到扩展实际读取的容器，面板可以列出目标；分享成功后在后台导入，失败时用系统通知提醒（点通知才打开窗口）。更多来源的文件路径可以识别。
- Headless / 网页连接：无参数的接口调用可以正常返回，登录后能进入主界面，首启向导可以走完；同一数据目录可以再次启动；指定 `--relay` 时走中转出站；网页接口拒绝跨站 WebSocket 升级。
- 中文更新提示去掉多余换行。
- 发行：Headless 服务端的打包任务会先构建依赖，干净的 CI 环境可以打出服务端安装包。
