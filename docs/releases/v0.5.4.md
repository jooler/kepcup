# KepCup 0.5.4

0.5.3 之后的版本。可以和 Bot 语音对话：对着麦克风说话，停顿后自动发送，回复以语音气泡播报，说话就能打断。每个 Bot 有独立的强调色，换上传头像不再丢色。工作台事项默认按开始时间排列，任务做完后执行报告直接出现在任务详情里。代码文件用带行号的查看器打开。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **语音对话**：私聊里，发送键左边可以进入语音对话（需要可用的语音识别和语音合成）。对着麦克风说话，说完停顿后发送键变绿，稍等会自动发出，也可以马上点发送；一直不说话会取消。发出去的是转写文字，并带上原始录音；Bot 直接读这段文字，不再为录音另开转写任务。语音模式下双方消息都是语音气泡，Bot 的回复会自动播报。播报时可以直接说话打断，或点停止。点气泡可以重听，并暂时关掉自动播报，直到你再发一段语音。用量页把这类播报记为「语音播报」。
- **Bot 强调色**：头像设置新增「强调色」页签，颜色与头像形状、是否上传分开保存。预置头像、名字、@ 提及、发送键和语音键、看板与工作台里的执行者，以及你在这个会话里的消息气泡，都跟着强调色走。上传头像或重置头像形状不会改颜色；也可以恢复默认的黑白色。
- **代码查看**：对话里的代码和配置文件用代码查看器打开，带行号、语言名，长行可以横向滚动。高亮按语言按需加载；认不出语言或文件过大时按纯文本显示。

## 改进

- **任务执行报告**：任务详情里直接展示执行报告；执行过程在运行中展开，结束后折叠。已完成的任务卡写明「任务已完成，点击查看执行报告」。Bot 不再把整段结果原文转进对话，回复里会自己总结关键结果和注意事项。
- **工作台事项**：事项默认按开始时间排序，没有时间的排在后面。栏头「更多」里可以打开「自定义排序」再拖拽调整；关掉后回到时间顺序，手动排过的顺序会留着。卡片底栏改为执行者、执行时间，然后是主操作。
- **工作台备忘**：拖拽把手收进卡片底部，不悬停时不占宽度。已经转成事项的备忘会变淡，悬停时恢复。空的「未分组」不再占位，新建备忘后立刻出现。关联事项取消后，备忘恢复普通样式和标签；重新打开事项后标签会回来。
- **文件与对话**：Bot 交出的多个文件收成一张卡片、多行排列，大小等信息在右侧。语音附件和音频文件用同一个播放器，可以暂停、看进度。消息组上下留白加大。日程和工作台来源提示过长时会换行，不再被挤成一行。侧栏里工作台入口的选中高亮与对话条目一致。

## 修复

- 右栏已绑定的工作目录，即使不在最近列表里，也不再显示成「未设置」。在访谈里选定目录后，不用刷新就能在详情里看到。
- 正在看某个会话的任务详情时，切到别的 Bot 再切回来，仍停在任务详情。
- 表格全屏时顶栏按钮可以点到；复制菜单不再被挡住。表格下载已去掉。
- 代码高亮放宽到约 2 万行，不再另设字符上限。
- 「计算机操控」设置卡的「在设置中打开」会进入对应分区。
