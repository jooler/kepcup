# KepCup 0.2.0

0.1.2 之后的小版本：macOS 系统分享接收、记忆硬约束、Pi 1.4、静默更新与项目详情改版。

## 新增

- macOS Share Extension（D94）：任意 App 的系统分享面板可将文件/图片/文本送进 KepCup；以附件路径与元数据交给 Bot，不把全文塞进模型上下文。
- 记忆硬约束：确定性注入与反思去抖，降低关键事实漏召回与重复反思抖动。
- Bot 文件卡片与放大预览：对话里的文件更易点开查看。
- 静默下载更新：后台拉更新，顶部通知改为浮层；修复重启安装被窗口隐藏拦截等问题。

## 改进

- Agent 运行时升级到 Pi 1.4.0（不含 pi-durable），并补边界加固与偏离登记。
- 项目详情页改为分类–详情布局，并加强自动保存与窄屏导航。
- 本机调研报告：Agent 长期记忆对照、记忆评测数据集分级接入草案（reports，非设计权威）。

## 修复

- 分享扩展：签名容器、打包降级、投递失败恢复与清扫长尾。
- 更新通道：`awaiting-user` 安全语义与手动检查。
- 记忆 job 生命周期在去抖窗口下的加固。
- Windows CI：工具输出 spill 路径跨平台规范化。

## 平台与安装包

与 0.1.2 相同：macOS dmg/zip、Windows 合并 NSIS、Linux AppImage/deb。已安装用户会经应用内更新收到本版。
