# KepCup 0.5.13

0.5.12 之后的版本。这一版让邮件支持标记、标签、移动、删除、草稿和文件夹管理，并上架阿里企业邮和 sciverse 文献检索插件。从市场安装插件时可以看到下载进度，MCP 配置完成后会自动连接并批准工具。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **邮箱内部写操作（D144）**：邮件支持标记、标签、移动、删除、草稿和文件夹管理。邮件插件 1.2.0 已随宿主发布。
- **阿里企业邮插件**：新增 mail-aliyun 1.2.0，并已上架插件市场。
- **sciverse 文献检索插件**：新增 mcp-sciverse（内嵌官方 sciverse-mcp-server），并已上架。
- **插件安装进度**：从市场安装插件时，弹窗会显示下载进度和速度。
- **MCP 配置后自动接通**：MCP 插件配置完成后会自动连接，并批准全部工具。
- **扩展中心 MCP 服务器管理**：实例型插件管理视图补齐「MCP 服务器」管理区。

## 改进

- 按钮的鼠标样式已统一。
- 插件构建在安装依赖失败时会清理临时目录，并补充了平台与产物漂移说明。
- 下架语雀（mcp-yuque）插件。
- 腾讯文档插件 1.0.3 已上架插件市场。

## 修复

- 正在输入时如果收到 Bot 新消息，输入框里的草稿不会再被清空。
- 安装同意卡里的配置表单现在能正确写回，确认按钮可以点。
- 账号视图按插件隔离，不再出现跨插件串台。
- 卡片里的超长链接不再撑破布局，改为在容器内横向滚动。
- 插件贡献的 server 调用闸与注入侧口径对齐，按当前有效启用的集合放行。
- sciverse 插件的构建产物会去掉脚手架文件；打包失败时清理临时目录。
