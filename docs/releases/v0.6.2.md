# KepCup 0.6.2

0.6.1 之后的版本。这一版升级了随发行版提供的 ACP 外部智能体，修订了凭据优先级与认证面板，并移除 InkCop 外部智能体（本机 InkCop 协作不受影响）。已安装的桌面版会通过应用内更新收到这一版。

## 改进

- **ACP 外部智能体升级**：Claude Agent 升到 0.113.0，Codex 升到 2.12.1，OpenCode 升到 2.4.2，Cursor 升到 2026.11.22，Google Antigravity 升到 1.5.2。OpenCode 现在由宿主控制权限，并加强配置隔离。
- **凭据策略**：登录按「复用本机官方登录 → 官方 OAuth / 登录命令 → API key」的优先级进行。可选择「复用本机登录」，智能体将沿用本机官方登录与个人配置；开启前会提示隔离不再生效的风险。KepCup 仍然不读取、不保存厂商凭据。
- **Google Antigravity 登录**：在二次确认后允许使用 Google 个人账号 OAuth（条款风险由你承担）；同时支持 Gemini API key 与 Gemini Enterprise。Vertex AI 入口暂不可用。

## 修复

- 外部智能体认证面板与状态同步问题。
- **移除 InkCop 外部智能体**：设置与发行目录中不再提供 InkCop ACP 条目。已把 Bot 主智能体设为 InkCop 的配置会回落到内置智能体；旧的 agent 会话不再启动。通过 `call_inkcop_agent` 进行的本机 InkCop 协作不受影响。
