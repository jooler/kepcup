# KepCup 0.5.14

0.5.13 之后的版本。这一版把图像和视频生成收成插件能力，并落地插件平台：能力模型条目、运行时宿主、状态徽标与活动抽屉，内置百炼和方舟试点。对话里支持整片拖拽附加文件，执行型插件有了私有数据目录和默认产物落点。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **图像/视频生成插件化（DEV-133）**：图像和视频生成改为通过插件提供，并完成收口。
- **插件平台（D124 / D125）**：能力模型条目契约、引擎注册表与解析链；PluginHost 运行时与媒体契约；插件状态徽标、活动抽屉和进度取消；治理管线与静态扫描。内置百炼、方舟插件，并以百炼文生图作为试点。
- **执行型插件数据目录（DEV-131）**：执行型插件有私有数据目录，生成产物有默认落点。
- **整片拖拽附加文件**：单聊、项目组和任务详情的整片视图都可以拖拽附加文件。

## 改进

- 消息气泡的圆角、内边距和字号集中到界面配置。
- 去掉任务消息上的来源标签。
- 插件超时改由插件自行声明；百炼试点改用 qwen-image-3.0 同步协议，并改为异步轮询。
- 试点插件的宿主版本要求锁定为 0.5.14 及以上。

## 修复

- 厂商配额或欠费错误与认证失败分开处理，不再误报「能力模型未配置」。
- 已投递的生成媒体不再登记成文件卡，避免临时文件留下死条目。
- 已投递媒体会随任务结果带上宿主备注，对话里不再重复发送。
- 兼容性或升级类错误会在提示里带出核心的具体原因。
- 百炼试点的地址错误已修正。
