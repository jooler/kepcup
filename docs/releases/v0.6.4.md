# KepCup 0.6.4

0.6.3 之后的版本。这一版改进了应用内更新的交互，调整了对话里未勾选通知的展示方式，并把消息隐藏与输入草稿迁到本机 IndexedDB。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **未勾选通知的展示**：未勾选的通知或过程类不再一律隐藏。30 天内的未读条目会照常出现在对话里，打开会话读过之后再收起；已经显示的条目会保持可见，直到切换到其他会话。项目组沟通页的未读徽标也按同一口径计算。

## 改进

- **更新交互**：侧栏更新按钮改为圆形进度环，整个流程收敛到一张进度卡片——就绪后可直接「应用更新」，破坏性更新的确认也放在卡片内。取消或跳过某个版本后不会再自动下载，但可以在设置里手动「检查更新」，并点「下载此版本」恢复。
- **低版本打开高版本数据**：如果用较低版本打开了被较高版本写过的本地数据，会给出专用提示，并提供「检查更新」入口；此时更新检查可以正常完成，避免卡在「检查中」或下载完成后无法安装。
- **本机草稿与消息隐藏存储**：消息隐藏状态和输入框草稿从 localStorage 迁到 IndexedDB，按会话分别保存，避免整表重写和配额问题。

## 修复

- 消息悬停操作钮与内容垂直居中，「来自 X」等提示行移出内容行外。
- 「更多」按钮改到外侧，弹层打开期间操作钮保持可见。
- 修复通知已读标记在无变化时仍写入，可能导致界面卡住的问题。
