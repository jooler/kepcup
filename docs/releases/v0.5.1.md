# KepCup 0.5.1

0.5.0 之后的版本。市场卡片改用插件自带的图标（随签名索引内联，不再用首字母占位），切换界面语言后设置里的分区名和主题选项会马上更新，签名索引同步失败时也能看到更具体的原因。已安装的桌面版会通过应用内更新收到这一版。

## 改进

- 市场图标：签名市场索引时从插件包读取图标，写成 `summary.icon` 内联 data URI（原始文件不超过 64 KiB）。扩展中心市场卡片用 `PluginIcon` 显示插件自有图标，缺图标或图标不可用时仍回落宿主默认图标；列表不再发起远程图片请求。上架校验把「未声明图标」改为错误；超过市场索引体积上限时给出警告。相关约定写进设计 51、DEV-053、插件开发指南与签名脚本。
- 设置语言：切换界面语言后，设置左侧分区名和「通用 → 外观」的主题下拉选项会立刻换成新语言，不必刷新或重开设置。

## 修复

- 签名索引同步：网络层失败时，状态文案会带上 undici 的真实原因（例如 DNS 失败或连接超时），不再出现自我重复的「fetch failed: fetch failed」。
