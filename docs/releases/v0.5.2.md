# KepCup 0.5.2

0.5.1 之后的版本。新增 Linux RPM / Flatpak / Snap 发行渠道，头像支持圆形与圆角方遮罩，Bot 增加 `kind` 分类（编程 Bot 可注入 coding_rules），并补上 Security Policy。已安装的桌面版会通过应用内更新收到这一版（AppImage / deb / rpm / 桌面安装包）；Flatpak / Snap 由各自渠道更新。

## 改进

- **Linux 更多渠道**：GitHub Releases 额外提供 RHEL 9/10 可用的 rpm（AlmaLinux 9 基线，x86_64 / aarch64，含安装冒烟），以及自托管 `.flatpak`（freedesktop 26.08）与 classic `.snap`（core24）。rpm 走应用内更新；Flatpak / Snap 关闭应用内更新，由对应包管理更新。
- **头像遮罩**：上传头像可选圆形或圆角方；成员预览重建时保留遮罩。
- **Bot 分类**：`bot.kind` 列与读取归一；访谈 `save_profile` 可设分类；编程 Bot 注入 `coding_rules`。
- **任务计划**：执行计划改为右上角浮层清单。
- **更新提示**：侧栏更新提示改为居中对话框。
- **生产构建**：正式产物关闭 DevTools。
- **Security Policy**：根目录 `SECURITY.md`，并开启 GitHub 私密漏洞报告。

## 修复

- `setAvatarMask` 非法值归一为 `INVALID_INPUT`。
- 迁移回放补齐 0059/0060 增量列摘除相关测试。
