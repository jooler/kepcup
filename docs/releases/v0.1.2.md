# KepCup 0.1.2

0.1.1 之后的小版本：任务 Loop Harness、英文界面、InkCop 同机协作，以及通讯录与工作台体验。

## 新增

- 任务执行过程页：点开任务卡即可看该任务的 Agent 步骤、工具结果与进度。
- 任务 Loop Harness（D93）：自动上下文压缩、结构化计划（`update_plan`）、软预算与空转检测。
- 英文界面：语言跟随用户；设置与扩展中心等目录文案补齐。
- InkCop 同机应用协作：扩展中心启停；Bot 详情关联智能体，以 `call_inkcop_agent` 工具交接（非整轮直连）；支持 API 密钥与可选服务地址。
- 设置注册中心：分层贡献与通用适配器。
- 通讯录：项目组进通讯录；从对话列表移除改为可恢复归档。
- 智能体：默认模型与按模型的 effort 选项。

## 改进

- 项目 wiki：项目组内沉淀默认留在项目 wiki；文档口径与 D92 对齐。
- InkCop 协作卡片：启停行与说明文案收口；未暴露智能体时给出明确提示。

## 修复

- InkCop：不再像「每条消息整轮 divert」；`agent_not_exposed`（403）有提示。
- 工作台：备忘改正文不再把卡片顶到最前；备忘操作行钉在卡片底部；切换视图保留输入草稿。
- 设置：InkCop 设置目录登记与类型检查。

## 平台与安装包

与 0.1.1 相同：macOS dmg/zip、Windows 合并 NSIS、Linux AppImage/deb。已安装用户会经应用内更新收到本版。
