# KepCup 0.5.12

0.5.11 之后的版本。这一版给 Bot 增加了长报告卡和私聊便签，任务直注支持附件，并把插件凭据收进设置卡、修好 MCP 的 Bearer 头与缺凭据误发。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **长报告卡（report）**：Bot 可以发出「摘要 + 分节正文 + 结论」的报告卡；分节默认收起，可展开全文。结果文字超过约 200 字时，优先发报告卡，对话里只点要点。
- **Bot 详情「便签」**：私聊里可以为该 Bot 记下用户私有速记。
- **任务直注附件**：任务详情的注入坞支持附带文件；图片会进入视觉通道，若当前模型没有视觉能力，会弹出看图模型配置卡。
- **插件凭据设置卡**：插件工具服务的 token 等凭据可以登记成设置卡。
- **MCP Header 凭据方案**：请求头模板可声明 `bearer` 方案；保存时去掉多余的 `Bearer` 前缀，发送时自动补上。腾讯文档插件 1.0.3 已按此声明，说明改为粘贴裸 token。

## 改进

- Bot 列表头像更大。
- Bot 详情的 tab 会按对话记住，并在重启后恢复。
- MCP 实例授权收束到插件卡；加号弹框打开时会刷新插件清单。
- 应用校验会检查 MCP header 的凭据方案声明。

## 修复

- 委派任务的审批卡、提问卡会在任务详情页同源显示。
- 缺凭据时在本地判定为未配置，不再把占位字符串发给服务端。
- 列出工具失败时，原因会显示在能力状态和日志里。
