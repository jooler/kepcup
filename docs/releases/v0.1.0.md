# KepCup 0.1.0（内测首发）

KepCup 是一个本地优先的 Bot 运行时桌面应用：你把常用的助手（编程、文档、事务、行政）接进来，它们在你的机器上、按你给定的权限与工作目录干活，对话、记忆、知识库与执行环境都留在本地。0.1.0 是第一个可用的内测版本，基础能力已完整跑通。

## 这个版本包含什么

- **桌面应用**：Electron + Svelte 5 + TypeScript，中文界面，macOS / Windows / Linux 三平台打包，应用内自动更新。
- **多 Bot 对话与协作**：一对一与群聊，`@` 触发、Bot 之间连锁 `@`；项目组（成员、任务、共享上下文与写入租约）。
- **执行与工具**：文件读写、命令执行、Git 操作，接入可配置沙箱；工具调用经统一网关做身份、路径检查与审计。
- **权限与审批**：命令白名单、逐次审批、对话级放行、无人值守模式；敏感操作在界面里确认后才执行。
- **记忆与知识库**：长期记忆与用户画像、对话中的自动反思与整理；Wiki 的摄取、维护与全文检索，资料可来自文件、网页与对话。
- **技能**：技能的扫描、注册与按需生成，文件类任务可按技能路由。
- **连接应用与外部智能体**：连接第三方应用（Notion、Linear、自建服务等，含本机 MCP 接入）与 ACP 外部智能体，支持把任务交接给另一个 Bot。
- **主动与定时**：定时任务（cron）、网页监看、到点唤醒后主动汇报。
- **浏览器与媒体**：受管浏览器页面、网页抓取，以及图片理解 / 生成、语音合成、音视频转写等媒体能力。
- **本机环境**：环境体检与依赖安装，Windows 上通过 WSL rootfs 提供 Linux 执行环境（x64 / arm64 双架构）。

## 平台与安装包

| 平台 | 产物 |
|---|---|
| macOS（Apple Silicon / Intel） | `.dmg` 首次安装，`.zip` 供应用内自动更新 |
| Windows（x64 / arm64） | 合并的 NSIS 安装包（`KepCup Setup X.Y.Z.exe`） |
| Linux（x64 / arm64） | AppImage 与 `.deb` |

macOS 与 Windows 的自动更新走 GitHub Releases；已安装的用户会在后台检查并下载更新。

## 已知限制

- 这是首个内测版本，功能仍在收敛中，接口与界面细节可能继续调整。
- Windows 直接下载的安装包暂未做代码签名，首次运行会出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。
- 商店渠道（Microsoft Store）这一版只产出 MSIX，正式上架流程随后续版本走。
- Linux 不提供 Flathub 包；AppImage 支持应用内静默更新，`.deb` 更新时会弹出权限确认。
