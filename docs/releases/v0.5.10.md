# KepCup 0.5.10

0.5.9 之后的补丁版本。主要是把 CI 上的偶发失败和 lint 报错收干净，顺带修了微应用 SDK 文档生成里的两处转义错误。已安装的桌面版会通过应用内更新收到这一版。

## 修复

- **微应用 SDK 文档**：collections 的文档示例原来写成单引号串，模板占位符 `${...}` 会原样露出来；栈帧正则里的 `\d` 在模板串中被吃掉，变成 `/:d+:d+/`。两处都已修正。
- **测试稳定性**：AuthStore 首启建号用例要跑三次 scrypt（N=2^17）校验，CI 慢机上会破默认 5 秒超时，单独放宽到 30 秒；反斜杠包路径用例只在 POSIX 上跑（Windows 的 `writeFileSync` 把反斜杠当分隔符，造不出非法路径）；workdirs 本机端口用例改用 `HTTP_CODE` 前缀断言，避免沙箱拒绝日志里的 PID（如 `curl(6200)`）被旧断言当成成功码 200。
- **lint**：桌面端三处（BotWidgetDetail 未用的 `Trash2`、WidgetRuntime 诊断限流表改 `SvelteMap`、micro-app-audio 短路赋值）与测试里四处未用变量（craft/p2 废弃夹具、service 时钟改 `const`、垫片里未用的 `spoken` 数组）。
