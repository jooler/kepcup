# KepCup 0.5.10

0.5.9 之后的版本。桌面计算机操控改为随包的 CuaDriver；设置里的模型与智能体、供应商 Key、远程桌面壳和多客户端协作也一并跟上。已安装的桌面版会通过应用内更新收到这一版。

## 新增

- **计算机操控改用 CuaDriver**：去掉自研 provider，随包装入 CuaDriver 0.46.1；发版会校验签名与随包完整性。从旧版原生 helper 升级后，需要在系统设置里重新授权（权限记在 KepCup 主应用名下）。安装包每架构大约会增加 60MB。
- **远程模式壳**：可用 `KEPCUP_REMOTE_URL` 让桌面壳直连自建的 headless 服务端。
- **多客户端协作（D119–D121）**：在线状态、共享草稿、远端光标与归属。
- **任务直注与 Bot 详情三栏（D115–D117）**：可从 Bot 详情直接给任务注入指令；任务详情显示上下文用量与平均缓存命中率。
- **ACP 与外部智能体（D118）**：连接加固，接入 7 个新目标；设置页外部智能体转正，并带上品牌图标。
- **供应商多 Key**：支持轮询、别名与启停；停用的 Key 不再参与调用。自定义供应商可选「数据风格」并「获取模型」。
- **使用构成**：可按工具查看任务上下文用量。
- **沙箱向导**：支持创建并初始化 Lima 虚拟机。
- **后台任务**：默认使用内置智能体；「模型与智能体」合并为设置里的页签分区。

## 改进

- 模型行未单独设置时，详情页显示「使用默认设置」，下拉显示「默认」。
- 同一 run 内冻结系统提示词，计划移出 system，保住 prompt cache；改 Bot 模型后重试会立即用当前模型继续本 run。
- 设置页厂商图标改用 lobehub 矢量图标，并按明暗主题适配；旧供应商实例会按模板或接口根补齐图标。
- 拖拽分隔线的高亮色随主题改为纯黑或纯白。
- 备忘分组改用 tab 组织，卡片与分组操作收进「…」菜单。
- 登录门改用自定义标题栏，标题居中并支持拖拽窗口。
- OpenAI 兼容实例不再发送 `store`。
- 缓存命中率的分母补上 `cache_write`，与 contextTokens 同口径。

## 修复

- 任务详情时间线里追加的指令只显示注入内容，不再露出包裹结构。
- 真实供应商错误会透出；停用 Key 不再参与调用。
- 计算机操控：直采自检、截屏落盘、拖拽投递；窗口目标会自动恢复，拖拽默认走到前台。
