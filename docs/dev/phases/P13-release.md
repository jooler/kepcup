# P13 打包发布与首次启动

## 目标

产出三个平台可分发的签名安装包，支持自动更新与开机自启；新用户首次启动时经过简洁的引导完成必需配置；完成全量回归与性能检查。

## 依赖

全部前序阶段。

## 设计依据

- [design/07-local-runtime.md](../../design/07-local-runtime.md)（首次启动、环境体检）
- [design/09-tech-stack.md](../../design/09-tech-stack.md#桌面壳electron)（签名、公证、自动更新的代价）
- [design/12-ui-layout.md](../../design/12-ui-layout.md)（视觉与交互）

## 范围

包含：

- electron-builder 配置：
  - macOS：`dmg` + `zip`，arm64 与 x64 分别构建；签名（Developer ID）与公证（notarytool）。
  - Windows：`nsis`，x64 与 arm64；代码签名（证书或 Azure Trusted Signing）。
  - Linux：`AppImage` 与 `deb`，x64 与 arm64。
- 原生模块按各平台架构重新编译并打包；`resources/bin` 与 `resources/wsl` 按平台只打包对应文件。
- 自动更新（electron-updater）：检查更新、后台下载、提示重启；更新前等待正在进行的执行结束或由用户确认中断。
- 开机自启（`app.setLoginItemSettings`；Linux 写入 autostart desktop 文件），默认开启，可在设置页关闭。
- 首次启动引导：
  1. 欢迎与数据存放位置说明（`~/.kepcup/`，本地存储）。
  2. 配置至少一个模型厂商与 API key（可跳过，但无法与 Bot 对话，界面持续提示）。
  3. 权限：开机自启、系统通知。
  4. 沙箱准备：macOS 自动检测；Linux 检测并在需要时显示 sudo 修复命令；Windows 引导启用 WSL2（可跳过）。
  5. 创建第一个 Bot（提供 2～3 个人设模板）。
- 数据目录的版本迁移：应用升级时按迁移规则升级各库；升级前自动备份 `main.db`（保留最近 3 份）。
- 环境体检入口（设置页“诊断”）：核心服务状态、数据库、钥匙串、沙箱、工具链、磁盘占用、日志目录（可在文件管理器中打开）。
- 性能检查与优化。
- 全量回归：所有阶段的自动化测试 + 手工冒烟（这是发布门禁；发布前的开发迭代仍先跑定向测试，见 [05-testing.md](../05-testing.md#开发中如何跑测试)）。

不包含：

- 云端服务、账号体系、崩溃上报到远端（日志只保存在本地）。

## 任务

1. **打包配置**：`electron-builder.yml`；构建脚本在 CI 中按平台矩阵执行；签名所需的证书与密钥通过 CI 机密注入，不入库。
2. **自动更新**：更新源配置（发布平台待定时先使用 GitHub Releases，写成可替换的配置项）；更新提示的界面文案。
3. **开机自启**：设置页开关；macOS 需签名后验证。
4. **首次启动引导**：`features/onboarding/`；每一步可返回；完成状态写入 `settings`。
5. **迁移与备份**：启动时检测数据版本，需要迁移时先备份再迁移；迁移失败时恢复备份并显示错误。
6. **诊断页**。
7. **性能**：测量并优化到验收标准；长对话（1 万条消息）与大量 Bot（50 个）场景。
8. **回归**：执行所有阶段的测试与冒烟清单，结果写入 PROGRESS.md。

## 测试要求

- 在三个平台的干净系统（虚拟机）上安装、首次启动、完成引导、对话、执行命令、卸载。
- 从上一个构建版本自动更新到当前版本，数据完整。
- 迁移失败的模拟：恢复备份并提示。

## 验收标准

- [ ] 三个平台的安装包均已签名（macOS 已公证），安装时没有“未知开发者”警告（Linux 除外）。
- [ ] 自动更新可用；执行进行中时不会被更新强制中断。
- [ ] 开机自启默认开启且可关闭；开机后应用在托盘中运行。
- [ ] 新用户在 3 分钟内完成首次引导并与第一个 Bot 对话。
- [ ] Windows 上完成 WSL2 准备后命令无需逐条确认；跳过时处于逐条确认模式。
- [ ] 升级前自动备份，迁移失败可恢复。
- [ ] 诊断页能显示各子系统状态。
- [ ] 性能：冷启动到窗口可交互 ≤ 3 秒（中端机器）；打开 1 万条消息的对话 ≤ 500 毫秒；空闲时核心服务内存 ≤ 300MB；输入框按键到字符显示无可感知延迟。
- [ ] 所有阶段的自动化测试与手工冒烟全部通过。

## 注意事项

- 签名证书、公证凭据、更新发布凭据只存在于 CI 机密中。
- 打包产物中不得包含测试夹具、模拟模型服务、`KEPCUP_KEYSTORE=memory` 的代码路径（通过构建时常量剔除）。
