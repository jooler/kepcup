# 飞书（mcp-feishu）

让 KepCup Bot 读写你的飞书云文档：搜索、阅读、创建与更新文档（走飞书官方 MCP 的个人 MCP 服务）。

## 启用步骤

1. 安装并启用本插件（扩展中心 → 已安装）。
2. 创建个人 MCP 服务：浏览器打开 [open.feishu.cn/page/mcp](https://open.feishu.cn/page/mcp)，
   用飞书账号登录后「创建 MCP 服务」并一键授权，复制生成的**专属服务器地址**。
   - 该路径为飞书「个人调用远程 MCP 服务」（内测），无需创建企业自建应用。
   - 专属地址即密钥，请妥善保管，不要泄露给他人。
   - 2026-02-24 起新建服务有效期 7 天，可续期；到期后在实例表单里更新地址即可。
3. 扩展中心 → 已安装 → 飞书 →「管理」→「添加工具服务」，粘贴地址保存。
4. 在 Bot 详情勾选启用本插件，Bot 即获得飞书文档读写工具。

凭据（地址）只保存在本机 secrets，不会进入对话上下文或界面。
