# 阿里企业邮（阿里云企业邮箱）

为 KepCup 添加阿里企业邮账号。收发服务器已内置并锁定（标准版地址），用户只需填写邮箱地址和
「三方客户端安全密码」。收信模式 `auto`：连接后读 CAPABILITY，服务器支持 IDLE 就近实时推送，
否则自动回落轮询。

## 服务商侧配置（官方文档）

- 服务器与端口：<https://help.aliyun.com/zh/document_detail/36576.html>
- 三方客户端配置方法：<https://help.aliyun.com/zh/document_detail/36596.html>

| 协议 | 服务器 | SSL 端口 | 非加密端口 |
| --- | --- | --- | --- |
| IMAP 收信 | imap.qiye.aliyun.com | 993 | 143 |
| POP3 收信 | pop.qiye.aliyun.com | 995 | 110 |
| SMTP 发信 | smtp.qiye.aliyun.com | 465 | 25（80/587 未开通） |

- 登录用「三方客户端安全密码」，不是网页登录密码：网页版 设置 → 账户与安全 → 账户安全 →
  三方客户端登录安全管理 → 启用三方客户端安全密码并生成新密码。
- 阿里邮箱默认禁止三方客户端登录：管理员需为账号放行三方客户端访问策略，并开启
  POP3/IMAP 服务权限。
- 报「用户名或密码错误」但密码确认无误：通常是该账号已开启安全密码，需重新生成安全密码填入。

## 插件取舍

- 锁定标准版 `qiye.aliyun.com` 地址；信创版（`xc.aliyun.com`）、香港版
  （`imaphk.qiye.aliyun.com` / `smtphk.qiye.aliyun.com`）、旧版（`mxhichina.com`，仍有效）
  用户走「通用邮箱」插件自填。
- 2026-03 起新开通的**免费版**阿里邮箱不再支持 SMTP/POP/IMAP（付费版不受影响）：
  免费版账号无法用本插件（也无处可填），需升级付费版。
- POP3 不提供：插件走 IMAP + SMTP（多端同步），与官方推荐一致。
- 账号表单沿用内置「授权码」文案（core 派生，厂商不可定制），语义与安全密码一致：
  都是「专用于客户端的密码，不是网页登录密码」。
